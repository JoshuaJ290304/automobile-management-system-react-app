# Automobile Management System

A React application to manage automobile details using REST APIs.

## Features

- Add Car
- View Cars
- React Router Navigation
- Axios API Integration
- Bootstrap UI

## Technologies

- React
- Vite
- Bootstrap
- Axios
- React Router DOM

## Installation

```bash
npm install
```

Run the project

```bash
npm run dev
```

## API Endpoints

### Add Car

POST

```
https://host-demo-app.onrender.com/api/add-car
```

### View Cars

GET

```
https://host-demo-app.onrender.com/api/cars
```
