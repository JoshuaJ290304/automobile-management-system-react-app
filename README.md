# Automobile Management System

## Features

- Home Page
- Add Car
- View Cars
- Axios API Integration
- React Router
- Bootstrap UI

## Technologies

- React
- Vite
- Axios
- React Router DOM
- Bootstrap

## Installation

```bash
npm install
npm run dev
```

## API

### Add Car

POST

```
https://host-demo-app.onrender.com/api/add-car
```

### View Cars

GET

```
https://host-demo-app.onrender.com/api/cars
```
